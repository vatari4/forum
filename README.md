# Проект Блога

## Описание
Проект блога включает в себя функциональность для создания, редактирования, удаления и отображения постов, а также систему авторизации и аутентификации для пользователей. Реализован с использованием **React** для фронтенда, **Node.js** с **PostgreSQL** для бэкенда.

---

## Структура проекта

### Фронтенд

Фронтенд состоит из React-компонентов, взаимодействующих с сервером для отображения и управления постами. Взаимодействие с сервером осуществляется через HTTP-запросы, используя библиотеку `axios`.

1. **PostList.jsx** - Компонент для отображения списка постов.
2. **PostItem.jsx** - Компонент для отображения отдельного поста.
3. **PostForm.jsx** - Форма для создания и редактирования постов.
4. **api.js** - Утилита для работы с API (запросы к серверу).
5. **auth.js** - Утилита для работы с JWT-токенами (получение данных пользователя).

#### Основные функции:

- **Создание поста**: В форме для создания поста пользователь может ввести заголовок и контент, после чего пост отправляется на сервер.
- **Редактирование поста**: При редактировании поста данные из поста загружаются в форму, и после изменений они отправляются на сервер.
- **Удаление поста**: Для удаления поста используется подтверждение через модальное окно, где пользователь должен ввести слово "Подтвердить".
- **Авторизация**: Система авторизации использует JWT для подтверждения подлинности пользователя. Токен хранится в `localStorage`.

### Бэкенд

Бэкенд реализован с использованием **Node.js** и **Express**. Для хранения данных используется **PostgreSQL**.

1. **server.js** - Основной файл сервера, содержащий настройки Express и маршруты для обработки запросов.
2. **models/** - Папка с моделями данных для работы с базой данных.
   - `Post.js` - Модель для постов.
   - `User.js` - Модель для пользователей.
3. **routes/** - Папка с маршрутами для обработки запросов:
   - `posts.js` - Маршруты для работы с постами (создание, чтение, редактирование, удаление).
   - `auth.js` - Маршруты для авторизации и получения данных пользователя.
4. **utils/** - Утилиты для работы с JWT и подключением к базе данных.


### Запустить проект:

Для фронтенда:
**cd frontend**
**npm start**

Для бэкенда:
**cd backend**
**node server.js**

#### Маршруты:

- `POST /posts` - Создание нового поста.
- `GET /posts` - Получение всех постов.
- `GET /posts/:id` - Получение поста по ID.
- `PUT /posts/:id` - Обновление поста.
- `DELETE /posts/:id` - Удаление поста.
- `POST /auth/login` - Авторизация пользователя.
- `GET /auth/me` - Получение данных текущего пользователя.

### Модели данных (PostgreSQL)

#### 1. Таблица пользователей (`users`)

```sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(255) UNIQUE NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    password VARCHAR(255) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE posts (
    id SERIAL PRIMARY KEY,
    title VARCHAR(255) NOT NULL,
    content TEXT NOT NULL,
    user_id INT REFERENCES users(id) ON DELETE CASCADE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
